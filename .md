# Acarlar Elektrik Web Sitesi – Header ve Dil İkonu Düzenleme Talimatı

## Amaç

Bu düzenlemenin amacı Acarlar Elektrik web sitesinin üst menü tasarımını daha modern, hizalı ve profesyonel hale getirmektir.

Yapılacak iki ana geliştirme vardır:

1. Türkçe / İngilizce dil ikonlarının modern bir buton tasarımına dönüştürülmesi
2. Logo, açıklama ve menü alanlarının tek bir hizadaymış gibi düzgün yerleştirilmesi

Referans tasarım Radore web sitesindeki header yapısıdır.

---

# 1. Dil İkonlarının Modern Buton Haline Getirilmesi

## Mevcut Durum

Türkçe ve İngilizce ikonları sayfanın sağ tarafında dağınık ve eski tip görünmektedir.

## İstenilen Tasarım

Dil ikonları aşağıdaki özelliklere sahip olmalıdır:

* Sağ üst köşede bulunmalı
* Yuvarlak buton görünümünde olmalı
* İçinde bayrak simgesi olmalı
* Hover efektine sahip olmalı
* Arka planı koyu olmalı
* Modern UI görünümü olmalı

## Örnek HTML

```html
<div class="language-switcher">
    <a href="#" class="lang-btn active">
        <img src="img/tr.png" alt="Türkçe">
    </a>

    <a href="#" class="lang-btn">
        <img src="img/en.png" alt="English">
    </a>
</div>
```

## Örnek CSS

```css
.language-switcher{
    display:flex;
    align-items:center;
    gap:10px;
}

.lang-btn{
    width:40px;
    height:40px;
    border-radius:50%;
    display:flex;
    align-items:center;
    justify-content:center;
    background:#111827;
    border:2px solid #2d3748;
    transition:0.3s;
}

.lang-btn img{
    width:22px;
}

.lang-btn:hover{
    border-color:#f59e0b;
    transform:scale(1.08);
}

.lang-btn.active{
    border-color:#f59e0b;
}
```

# 2. Üst Menü (Header) Hizalama Sorununun Düzeltilmesi

## Mevcut Sorun

Header alanında şu elemanlar bulunmaktadır:

* Logo
* Firma açıklaması
* Menü (Ana sayfa, Hizmetler, Projeler vb.)

Bu elemanlar şu anda hizalı görünmemekte ve farklı seviyelerde durmaktadır.

Amaç tüm elemanların **tek bir düz çizgi üzerinde hizalanmış gibi görünmesini sağlamaktır.**

---

# Önerilen Layout Yapısı

Header flexbox sistemi ile düzenlenmelidir.

## HTML Yapısı

```html
<header class="main-header">

<div class="container header-row">

<div class="logo-area">
<img src="img/logo.png" alt="Acarlar Elektrik">
<div class="logo-text">
<h3>Acarlar Elektrik</h3>
<span>Elektrik & İletişim Çözümleri</span>
</div>
</div>

<nav class="main-menu">
<ul>
<li><a href="#">Ana Sayfa</a></li>
<li><a href="#">Hakkımızda</a></li>
<li><a href="#">Hizmetler</a></li>
<li><a href="#">Projeler</a></li>
<li><a href="#">Ulaşım</a></li>
<li><a href="#">İletişim</a></li>
</ul>
</nav>

<div class="header-right">
<!-- dil ikonları burada olacak -->
</div>

</div>

</header>
```

```css
.main-header{

    margin:0;

    color:#f59e0b;
}
```

# 3. Sonuç

Bu düzenleme ile:

* Dil seçimi modern bir görünüme kavuşur
* Menü hizaları düzelir
* Logo ve açıklama profesyonel görünür
* Header daha kurumsal görünür
* Radore sitesine benzer bir üst yapı elde edilir

---

# Ek Öneri

Header için aşağıdaki özellikler eklenebilir:

* Sticky header (sayfa kayarken sabit kalma)
* Menü hover animasyonu
* Dil ikonlarında tooltip
* Responsive mobil menü

Bu geliştirmeler sitenin profesyonel algısını artıracaktır.
